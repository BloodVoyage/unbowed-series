Unbowed I: Blood Rite Fanatic

A cold, predatory, and lethal dialogue overhaul that strips away all forced servility. Tailored for a ruthless Dunmer who despises weakness, this module replaces passive pleadings with venomous, arrogant, and blunt demands—treating Skyrim’s inhabitants not as patrons to serve, but as weaklings to exploit, plunder, or destroy.

Unbowed II: Unyielding Dragonborn

🛠️ Installation Guide

🚫 Mod Manager Requirement: Unbowed is NOT compatible with Vortex or any Nexus-derived mod management software. You must use Mod Organizer 2 (MO2) to install and deploy this mod family correctly.
  1. Download the desired archetype package (.7z) from the catalog table above.
  2. Install the archive directly into Mod Organizer 2 (MO2) and activate it in your mod list.
  3. Place the ESPFE plugin low in your load order to ensure dialogue overrides take absolute priority.

⚙️ AI Usage Disclosure & Transparency

In the interest of full technical transparency regarding community standards and mod development pipelines, the creation process behind the Unbowed series is structured as follows:

  • Dialogue (AI-generated): The dialogue text was rewritten in batches using the Google Gemini API. To set the style, I rewrote 100 main quest lines by hand in the archetype's voice and wrote a character guide (about four pages) describing how the character reacts in different situations; the AI worked from those. Given the scale (9,024 lines), writing it all by hand was not feasible. Lines are not individually reviewed before release; I correct them manually as I find issues during playthroughs. See Update Policy for how corrections are released.
  • Everything else (authored by me): Record mapping, string compilation, ESPFE flagging, and xEdit error auditing, done with custom Python scripts, SSEEdit, and xTranslator.
